# 4360902 Microprocessor and Controller Applications (Microprocessor & Controller Applications): Important Questions

Diploma Semester 6, Electrical, GTU. Five questions per chapter, most repeated first. English + Gujarati.
Selected from all 5 GTU papers (Summer 2024, Winter 2024, Summer 2025, Winter 2025, Summer 2026), matched with the official GTU syllabus.

## Unit 1: Basics of Microprocessor (માઇક્રોપ્રોસેસરની મૂળભૂત બાબતો)

1. What is an instruction? Classify the instruction set of 8085 microprocessor based on its function and explain each group with examples.
   - ઇન્સ્ટ્રકશન એટલે શું? 8085 માઇક્રોપ્રોસેસરના ઇન્સ્ટ્રકશન સેટનું તેના કાર્યના આધારે વર્ગીકરણ કરો અને દરેક ગ્રુપ ઉદાહરણ સાથે સમજાવો.
   - *Asked in S2026, W2025, S2025, W2024, most repeated in this unit*
2. Draw the architecture (block diagram) of 8085 microprocessor and describe the function of each part.
   - 8085 માઇક્રોપ્રોસેસરનું આર્કિટેકચર (બ્લોક ડાયાગ્રામ) દોરો અને દરેક ભાગનું કાર્ય વર્ણવો.
   - *Asked in S2026, S2025, W2024 (7 marks)*
3. Draw the pin diagram of 8085 microprocessor and explain the function of each pin.
   - 8085 માઇક્રોપ્રોસેસરનો પિન ડાયાગ્રામ દોરો અને દરેક પિનનું કાર્ય સમજાવો.
   - *Asked in S2026, S2025, W2025 (7 marks)*
4. Develop 8085 assembly programs: (1) addition of two 8-bit numbers, (2) subtraction of two 8-bit numbers, and store the result in memory.
   - 8085 એસેમ્બલી પ્રોગ્રામ બનાવો: (1) બે 8-બિટ સંખ્યાઓનો સરવાળો, (2) બે 8-બિટ સંખ્યાઓની બાદબાકી, અને પરિણામ મેમરીમાં સ્ટોર કરો.
   - *Asked in S2026, W2025, W2024 (7 marks)*
5. What are addressing modes? List the addressing modes of 8085 and explain each in detail.
   - એડ્રેસિંગ મોડ એટલે શું? 8085 ના એડ્રેસિંગ મોડની યાદી બનાવો અને દરેક વિગતવાર સમજાવો.
   - *Asked in S2026, W2025, S2025*

## Unit 2: Basics of Microcontroller 8051 (માઇક્રોકન્ટ્રોલર 8051 ની મૂળભૂત બાબતો)

1. Explain the architecture of 8051 microcontroller with its internal block diagram.
   - 8051 માઇક્રોકન્ટ્રોલરનું આર્કિટેકચર તેના આંતરિક બ્લોક ડાયાગ્રામ સાથે સમજાવો.
   - *Asked in S2026, W2025, W2024 (7 marks)*
2. Compare microprocessor and microcontroller.
   - માઇક્રોપ્રોસેસર અને માઇક્રોકન્ટ્રોલરની સરખામણી કરો.
   - *Asked in S2026, S2025, W2024*
3. Draw the pin diagram of 8051 microcontroller and explain the function of each pin (or any ten pins).
   - 8051 માઇક્રોકન્ટ્રોલરનો પિન ડાયાગ્રામ દોરો અને દરેક પિનનું (અથવા કોઈ પણ દસ પિનનું) કાર્ય સમજાવો.
   - *Asked in S2026, S2025 (7 marks)*
4. Write down the applications of microcontroller / 8051 microcontroller.
   - માઇક્રોકન્ટ્રોલર / 8051 માઇક્રોકન્ટ્રોલરના ઉપયોગો લખો.
   - *Asked in S2026, W2025, S2025, easy scoring question*
5. Write in detail about the Timer/Counter of 8051 microcontroller (TMOD and TCON registers).
   - 8051 માઇક્રોકન્ટ્રોલરના ટાઇમર/કાઉન્ટર વિશે વિગતવાર લખો (TMOD અને TCON રજિસ્ટર).
   - *Asked in S2026, W2025, W2024*

## Unit 3: Microprocessor and Microcontroller Applications (માઇક્રોપ્રોસેસર અને માઇક્રોકન્ટ્રોલરના ઉપયોગો)

1. Construct the block diagram for temperature control of a furnace using a microprocessor and explain it.
   - માઇક્રોપ્રોસેસરનો ઉપયોગ કરીને ભઠ્ઠીના તાપમાન નિયંત્રણ માટે બ્લોક ડાયાગ્રામ બનાવો અને સમજાવો.
   - *Asked in S2026, W2025, S2025, W2024, most repeated application*
2. Describe the block diagram for SCR firing angle control using a microprocessor and explain it.
   - માઇક્રોપ્રોસેસરનો ઉપયોગ કરીને SCR ફાયરિંગ એંગલ કંટ્રોલ માટે બ્લોક ડાયાગ્રામ વર્ણવો અને સમજાવો.
   - *Asked in S2026, W2025, S2025, W2024*
3. Explain the data transfer schemes (techniques) used in a microprocessor-based system.
   - માઇક્રોપ્રોસેસર આધારિત સિસ્ટમમાં વપરાતી ડેટા ટ્રાન્સફર પદ્ધતિઓ (ટેકનિક) સમજાવો.
   - *Asked in S2026, S2025, W2024 (7 marks)*
4. Compare various types of semiconductor memories: RAM and ROM, PROM, EPROM and EEPROM.
   - વિવિધ પ્રકારની સેમિકન્ડક્ટર મેમરીની સરખામણી કરો: RAM અને ROM, PROM, EPROM અને EEPROM.
   - *Asked in S2026, W2025, S2025, W2024 in some form in every paper*
5. Describe external memory interfacing with 8051 microcontroller.
   - 8051 માઇક્રોકન્ટ્રોલર સાથે એક્સટર્નલ મેમરી ઇન્ટરફેસિંગ વર્ણવો.
   - *Asked in S2026, S2025, W2024*

## Unit 4: Recent Trends in Controller (કન્ટ્રોલરમાં આધુનિક પ્રવાહો)

1. Draw the architecture of PLC and explain the function of each component.
   - PLC નું આર્કિટેકચર દોરો અને દરેક કોમ્પોનન્ટનું કાર્ય સમજાવો.
   - *Asked in S2026, W2025, S2025 (7 marks)*
2. Draw the block diagram of SCADA, explain its components and write the applications/functions of SCADA.
   - SCADA નો બ્લોક ડાયાગ્રામ દોરો, તેના કોમ્પોનન્ટ સમજાવો અને SCADA ના ઉપયોગો/કાર્યો લખો.
   - *Asked in S2026, W2025, S2025 (7 marks)*
3. Write the difference between a relay panel and PLC.
   - રિલે પેનલ અને PLC વચ્ચેનો તફાવત લખો.
   - *Asked in S2026, W2025, S2025*
4. Write the basic difference between PLC and a digital computer.
   - PLC અને ડિજિટલ કમ્પ્યુટર વચ્ચેનો મૂળભૂત તફાવત લખો.
   - *Asked in S2026, W2025*
5. Write the advantages and disadvantages of PLC. What factors affect the selection of a PLC?
   - PLC ના ફાયદા અને ગેરફાયદા લખો. PLC ની પસંદગીને કયા પરિબળો અસર કરે છે?
   - *Asked in W2025, S2025*
