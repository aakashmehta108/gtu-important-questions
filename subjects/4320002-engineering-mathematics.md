# 4320002 Engineering Mathematics: Important Questions

Diploma Semester 2, All Branches (Common), GTU. Five questions per chapter, most repeated first. English + Gujarati.
Selected from all 7 GTU papers (Winter 2023, Summer 2023, Winter 2024, Summer 2024, Winter 2025, Summer 2025, Summer 2026), matched with the official GTU syllabus.

## Unit 1: Matrices (શ્રેણિકો)

1. Solve the system of linear equations using the matrix method, e.g. 5x + 3y = 11, 3x - 2y = -1.
   - શ્રેણિક પદ્ધતિનો ઉપયોગ કરીને સમીકરણ સંહતિનો ઉકેલ મેળવો, દા.ત. 5x + 3y = 11, 3x - 2y = -1.
   - *Asked in ALL 7 papers*
2. If A = [3 1; -1 2], prove that A^2 - 5A + 7I = 0 (matrix polynomial identity).
   - જો A = [3 1; -1 2] હોય, તો સાબિત કરો કે A^2 - 5A + 7I = 0 (શ્રેણિક બહુપદી નિત્યસમ).
   - *Asked in 4 papers: W2023, W2024, S2024, W2025*
3. Prove that (AB)^T = B^T A^T for the given matrices A and B.
   - આપેલા શ્રેણિકો A અને B માટે સાબિત કરો કે (AB)^T = B^T A^T.
   - *Asked in 4 papers: W2023, S2023, W2024, S2025*
4. Prove that (A + B)^T = A^T + B^T for the given matrices A and B.
   - આપેલા શ્રેણિકો A અને B માટે સાબિત કરો કે (A + B)^T = A^T + B^T.
   - *Asked in 4 papers: W2023, S2023, S2024, W2025*
5. Find the inverse of a 3 x 3 matrix using the adjoint method.
   - Adjoint (સહઅવયવ) પદ્ધતિનો ઉપયોગ કરીને 3 x 3 શ્રેણિકનો વ્યસ્ત શોધો.
   - *Asked in 3 papers: S2023, S2025, S2026*

## Unit 2: Differentiation and its Applications (વિકલન અને તેના ઉપયોગો)

1. The equation of motion of a particle is s = t^3 - 6t^2 + 8t - 6. Find its velocity and acceleration at a given time t.
   - એક કણની ગતિનું સમીકરણ s = t^3 - 6t^2 + 8t - 6 છે. આપેલા સમય t એ તેનો વેગ અને પ્રવેગ શોધો.
   - *Asked in 6 papers: W2023, S2023, W2024, W2025, S2025, S2026*
2. Find dy/dx using the product and quotient rules, e.g. y = (x^2 - 1)/(x^2 + 1), y = log x . sin x, y = (log x)/x.
   - ગુણાકાર અને ભાગાકારના નિયમોનો ઉપયોગ કરીને dy/dx શોધો, દા.ત. y = (x^2 - 1)/(x^2 + 1), y = log x . sin x, y = (log x)/x.
   - *Asked in 6 papers: W2023, S2023, S2024, W2025, S2025, S2026*
3. Differentiate using logarithmic differentiation, e.g. y = x^x, y = (sin x)^x, y = x^(cos x).
   - લઘુગણકીય વિકલન (logarithmic differentiation) નો ઉપયોગ કરીને વિકલન કરો, દા.ત. y = x^x, y = (sin x)^x, y = x^(cos x).
   - *Asked in 4 papers: S2023, W2024, S2025, S2026*
4. If y = A cos pt + B sin pt, prove that d^2y/dt^2 + p^2 y = 0 (second order derivative proof).
   - જો y = A cos pt + B sin pt હોય, તો સાબિત કરો કે d^2y/dt^2 + p^2 y = 0 (દ્વિતીય કક્ષાના વિકલિતનો પુરાવો).
   - *Asked in 4 papers: S2023, W2024, S2024, S2025*
5. Find the maximum and minimum values of the function f(x) = 2x^3 - 3x^2 - 12x + 5.
   - વિધેય f(x) = 2x^3 - 3x^2 - 12x + 5 ના મહત્તમ અને ન્યૂનતમ મૂલ્યો શોધો.
   - *Asked in 3 papers: W2023, S2024, W2025*

## Unit 3: Integration and its Applications (સંકલન અને તેના ઉપયોગો)

1. Evaluate integrals by parts, e.g. ∫ x e^x dx, ∫ x log x dx, ∫ x sin x dx.
   - ખંડશઃ સંકલન (integration by parts) વડે સંકલન કરો, દા.ત. ∫ x e^x dx, ∫ x log x dx, ∫ x sin x dx.
   - *Asked in ALL 7 papers*
2. Evaluate the definite integral using the property of definite integrals, e.g. ∫(0 to pi/2) sin x/(sin x + cos x) dx.
   - નિયત સંકલનના ગુણધર્મનો ઉપયોગ કરીને સંકલન કરો, દા.ત. ∫(0 થી pi/2) sin x/(sin x + cos x) dx.
   - *Asked in ALL 7 papers*
3. Find the area of a region using integration, e.g. area of the circle x^2 + y^2 = a^2, or the area under y = x^2 between x = 1 and x = 4.
   - સંકલનનો ઉપયોગ કરીને પ્રદેશનું ક્ષેત્રફળ શોધો, દા.ત. વર્તુળ x^2 + y^2 = a^2 નું ક્ષેત્રફળ, અથવા y = x^2 નીચે x = 1 અને x = 4 વચ્ચેનું ક્ષેત્રફળ.
   - *Asked in 6 papers: W2023, S2023, W2024, S2024, W2025, S2026*
4. Evaluate integrals by the method of substitution, e.g. ∫ x^2/(1 + x^6) dx, ∫ cos(log x)/x dx, ∫ (6x + 2)/(3x^2 + 2x + 3) dx.
   - અવેજી પદ્ધતિ (method of substitution) વડે સંકલન કરો, દા.ત. ∫ x^2/(1 + x^6) dx, ∫ cos(log x)/x dx, ∫ (6x + 2)/(3x^2 + 2x + 3) dx.
   - *Asked in 6 papers: W2023, W2024, S2024, W2025, S2025, S2026*
5. Evaluate basic integrals by splitting into standard forms, e.g. ∫ (x^2 + 2x + 9)/x dx, ∫ (1 - 3x)^2/x^3 dx.
   - પ્રમાણભૂત સ્વરૂપોમાં વહેંચીને મૂળભૂત સંકલન કરો, દા.ત. ∫ (x^2 + 2x + 9)/x dx, ∫ (1 - 3x)^2/x^3 dx.
   - *Asked in 3 papers: W2023, W2024, S2025*

## Unit 4: Differential Equations (વિકલ સમીકરણો)

1. Solve the linear differential equation dy/dx + Py = Q using the integrating factor, e.g. dy/dx + 2y = 3e^x, dy/dx + y tan x = sec x.
   - સંકલ્યકારક અવયવ (integrating factor) નો ઉપયોગ કરીને સુરેખ વિકલ સમીકરણ dy/dx + Py = Q ઉકેલો, દા.ત. dy/dx + 2y = 3e^x, dy/dx + y tan x = sec x.
   - *Asked in ALL 7 papers*
2. Solve the first order differential equation by the variable separable method, e.g. y(1 + x) dx + x(1 + y) dy = 0, dy/dx = 1 + x + y + xy.
   - ચલ વિભાજન પદ્ધતિ (variable separable method) વડે પ્રથમ કક્ષાનું વિકલ સમીકરણ ઉકેલો, દા.ત. y(1 + x) dx + x(1 + y) dy = 0, dy/dx = 1 + x + y + xy.
   - *Asked in ALL 7 papers*
3. Find the order and degree of a given differential equation.
   - આપેલા વિકલ સમીકરણની કક્ષા (order) અને પરિમાણ (degree) શોધો.
   - *Asked in ALL 7 papers*
4. Find the integrating factor of the differential equation dy/dx + Py = Q (I.F. = e^(∫P dx)), e.g. for dy/dx + y/x = x.
   - વિકલ સમીકરણ dy/dx + Py = Q નો સંકલ્યકારક અવયવ (I.F. = e^(∫P dx)) શોધો, દા.ત. dy/dx + y/x = x માટે.
   - *Asked in 6 papers: W2023, S2023, W2024, S2024, W2025, S2026*
5. Solve the homogeneous differential equation, e.g. dy/dx = (x + y)^2, dy/dx = y/x + x sin(y/x).
   - સમાંગ વિકલ સમીકરણ (homogeneous differential equation) ઉકેલો, દા.ત. dy/dx = (x + y)^2, dy/dx = y/x + x sin(y/x).
   - *Asked in 4 papers: W2023, W2024, W2025, S2025*

## Unit 5: Complex Numbers (સંકર સંખ્યાઓ)

1. Express a complex number in polar form and find its modulus and principal argument, e.g. 1 + √3 i, -√3 + i, 1 - i.
   - સંકર સંખ્યાને ધ્રુવીય સ્વરૂપમાં દર્શાવો અને તેનો માનાંક તથા મુખ્ય કોણાંક શોધો, દા.ત. 1 + √3 i, -√3 + i, 1 - i.
   - *Asked in ALL 7 papers*
2. Simplify complex number expressions into a + ib form, e.g. (4 + 2i)/((3 + 2i)(5 - 3i)), (2 - 5i)/(1 + 3i).
   - સંકર સંખ્યાના પદોને સાદું રૂપ આપી a + ib સ્વરૂપમાં દર્શાવો, દા.ત. (4 + 2i)/((3 + 2i)(5 - 3i)), (2 - 5i)/(1 + 3i).
   - *Asked in ALL 7 papers*
3. Find the square root of a complex number, e.g. 5 + 12i, 7 + 24i, 4 + 3i.
   - સંકર સંખ્યાનું વર્ગમૂળ શોધો, દા.ત. 5 + 12i, 7 + 24i, 4 + 3i.
   - *Asked in 5 papers: S2023, W2024, W2025, S2025, S2026*
4. Simplify expressions of the form (cos aθ + i sin aθ)^m (cos bθ - i sin bθ)^n using De Moivre's theorem.
   - De Moivre ના પ્રમેયનો ઉપયોગ કરીને (cos aθ + i sin aθ)^m (cos bθ - i sin bθ)^n સ્વરૂપના પદોને સાદું રૂપ આપો.
   - *Asked in 5 papers: W2023, W2024, S2024, S2025, S2026*
5. Find the conjugate and modulus of a complex number, e.g. (2 + 3i)/(3 + 2i), (2 - 3i)(-2 + i).
   - સંકર સંખ્યાની અનુબદ્ધ સંકર સંખ્યા (conjugate) અને માનાંક (modulus) શોધો, દા.ત. (2 + 3i)/(3 + 2i), (2 - 3i)(-2 + i).
   - *Asked in 4 papers: W2023, W2024, S2024, S2025*
