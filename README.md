# GTU Important Questions (IMPQ)

Important questions for GTU subjects (BE and Diploma), selected from **GTU old question papers** and matched with the **official GTU syllabus**. Five questions per chapter, most repeated questions first, made to help you pass quickly.

Prepared by **Electro Tutor** (educational initiative), Vadodara.

## How to use

1. Find your subject code in the list below.
2. Open the subject file and prepare the questions chapter by chapter.
3. Question sets are updated as new GTU papers come out.

